# Redline Ridge

A 3D mountain-circuit arcade racer. Drive a silver BMW G90 M5 against 7 AI rivals
over 3 laps: heavy GTA-style handling, nitro, minimap, and keyboard + touch controls.

## Play

Open `index.html` in a browser, or play the hosted version via GitHub Pages
(enable Pages on this repo if it isn't already).

## Controls

- **Keyboard:** WASD / arrows to drive, Space for handbrake, N for nitro
- **Touch:** on-screen steering, throttle/brake, and nitro buttons
